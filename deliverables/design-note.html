Why: the model negotiates, the API refuses to record anything unauthorised. A bad commitment is rejected with a correction the agent must speak, and the transcript is audited afterwards for anything said without approval.

Bot 1 — loan settlement: avoidance vs hardship

open₹6,50,000Dues stated, breakdown only if asked
→
avoidanceRepeated excuseSalary delay, already paid, dispute
→
routeAvoidance or hardship?Avoidance: return to date. Hardship: affordability
→
pressureConsequencesRecovery notice, arbitration, CIBIL
→
close₹4,00,000 + dateLogged only if valid
Firm, not abusive: no police, no jail, no third-party disclosure. Avoidance gets a firm redirect to date and amount; genuine hardship gets an affordability conversation; a disputed payment goes to verification rather than repeated pressure.

Bot 2 — insurance renewal: the price ladder

→
objection“Zyada hai”Only now is the concession unlocked
→
concede once₹15,000Tied to confirming today
→
below floor₹12,000 requestRejected. Minimum authorised is ₹15,000
The brief asks for the highest achievable value, so the ladder is the design: the standard premium first, the authorised discount as a conditioned concession, and never below it.

Compliance decisions

RiskHow it is prevented
Agent invents a numberAmounts validated in code; unauthorised figures rejected before the agent can confirm
Vague commitment“Agle hafte”, “month end”, “agle shukravar” rejected until a real date is named
ThreatsLegal consequences stated factually; no police, jail or public shaming in the prompt
Wrong person told the duesIdentity gate sits before any amount, IDV or premium
Add-on price inventedExplicit rule: no add-on figure unless it exists; offer a quote instead
Self-harm mentionMandatory escalation with ticket, selling stops immediately
Silent or abusive callerNudge at 8s and 11s, then hang up; abusive caller escalated, never matched
